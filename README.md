# alpic
DUDESIGN x Alpic: product design work, starting with Tracks (agent harness and experiments dashboard)

The interactive 3D mountain from the Alpic sign-in page is in [`playground/mountain`](playground/mountain/README.md). From the repo root, run `npm run mountain` and open http://127.0.0.1:4173.

The Tracks interface prototype is in [`tracks`](tracks/README.md). From the repo root, run `npm run tracks` and open http://127.0.0.1:4174.
